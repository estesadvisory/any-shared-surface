# Feedback and dissent

Feedback in this project is a first-class object, kept beside the text it answers — never folded silently into someone else's words.

## Convention

- File name: `outline-<version>.feedback.<name>.md` (for example `outline-v0.2.feedback.chatgpt.md`).
- Every file is stamped by its author with:
  - **Author** — human name, or system name and provider.
  - **Date.**
  - **Stance** — concur, refine, or reject — and toward which claims.
  - **Disclosure** — interests that could colour the feedback, stated plainly. Agent reviewers are expected to disclose that they are systems of the kind this paper discusses.
  - **Evidence grades** for factual claims (verified / documented / anecdotal), and **what would change their mind**.

## A note on preserved disagreement

Grok and Claude agreed on substance and disagreed on sequencing — whether a governed channel's properties or a receiving agent's posture comes first. The v0.2 outline records both positions and the editor's call. That is the intended behaviour of this folder: disagreement is data.
